# April 2026 – Branch Change Log (track-reading-redesign)

## Overview
This branch introduces the Reading Diary experience (timeline, filters, detail pages, and note editing), adds daily diary entry upserts tied to progress tracking, and removes weighted genre tagging in favor of direct genre lists. It also renames user progress storage and updates migrations to align with the new schema.

## Highlights
- Reading Diary timeline with filters (genre/author/title), detail pages, and note editing.
- Track Reading now upserts daily diary entries and supports note capture.
- Genre weights removed; titles now store a direct `genre` array.
- Progress storage renamed to `library_user_progress` with updated migrations and references.
